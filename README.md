# usdzcheck

USDZ 模型包的校验与规范化 Go 库，供素材入库流程在内存中调用，无接口层、不落盘。

## 用法

```go
import "usdzcheck/usdz"

// 校验：返回全部问题，空切片表示合规。
issues := usdz.Validate(data)

// 规范化：仅当问题都属于可修复类别（已压缩、未对齐、目录条目）时
// 返回规范化后的字节；否则返回 nil 与完整问题清单。
out, issues := usdz.Normalize(data)
```

## 规则摘要

- 合规包：内容条目均不压缩、不加密，数据起始偏移 64 字节对齐，
  首条目为 usda/usdc/usd 图层，扩展名限于
  usda/usdc/usd/png/jpg/jpeg/m4a/mp3/wav（不区分大小写）。
- 目录条目（以 `/` 结尾）校验时忽略，规范化时去除。
- 问题原因：损坏、加密、不支持的压缩方式、已压缩、未对齐、
  首条目不是图层、扩展名不允许、路径非法、重名、校验值不符、超限。
- 输入或规范化输出超过 50 MiB 按超限拒收。
- 规范化结果确定性输出且幂等；保留条目顺序、名字、解压内容与修改时间。
